Lesson Bridge privacy

Updated October 28, 2026. This policy describes Guitar Trainer Lesson Bridge, the optional Chrome extension for Guitar Trainer Studio.

What you choose to inspect

When you click Scan this page, the extension reads the current page title and address, exposed resource links, bounded inline URL declarations, already loaded resource names and accessible same-origin frames. On TrueFire it may request the current lesson's player manifest using your existing browser session. It does not monitor your browsing in the background.

Downloads and transfers

Inspect timing and Test/Send actions can request selected resources from their providers. Score downloads are limited to 12 MiB; timing and manifest responses to 1,000,000 bytes. Requests may use your existing signed-in browser session. The extension does not read passwords or use Chrome's cookies API. Providers still receive ordinary network requests and apply their own privacy policies and access restrictions.

Send transfers the lesson title/address, selected score bytes, recording URL and timing to the Guitar Trainer tab at the address you choose. Guitar Trainer asks for review before applying the import. Recording previews contact the selected media provider; YouTube previews use youtube-nocookie.com. Playback may cause the browser to buffer/cache media. The extension does not export recording files.

Storage and your choices

The extension saves only your destination Guitar Trainer address in Chrome local extension storage. Scan results clear when the popup closes. After an explicit Send, an on-demand extension worker retains the selected resources temporarily in memory until that send finishes, including while you approve site access. It does not monitor browsing or automatically retry. A short send-status message is kept in browser-session storage so reopening the popup can show the result; it clears when the browser session ends. Lesson URLs, score bytes and timing are not saved by the extension. Chrome retains optional site permissions until you revoke them or uninstall the extension. Copy link and Copy sync points write only the requested content to your clipboard; links may include private, expiring access parameters. Avoid sharing those links.

Guitar Trainer is a separate app. If you explicitly save an imported score to its library, score bytes persist in that site's browser storage and can be included in library backups. Saved sync profiles can contain recording URLs and timing. Delete those items in the app or clear that site's storage to remove them. Uninstalling the extension does not delete the app's saved library.

No developer collection or advertising

The extension has no developer-operated collection service, analytics, advertising or sale of user data. It uses page/resource information only for the lesson discovery, preview and transfer actions described here. It does not send lesson data to the developer.

Contact and source

Questions: project issues. Do not post credentials, private lesson links or copyrighted files in public reports. Extension source.
