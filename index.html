Fretboard help

Blue: expected note. Green ✓: accepted note. Red × / !: missed note or completed with errors. Separate rings show held played pitches: green for accepted, red for wrong, purple when no current result applies. Rings disappear on release.

The selected tablature supplies string count, tuning and capo. Fret numbers are relative to the capo; position inlays follow physical frets. Open notes appear outside the nut. String thickness is a visual pitch cue.

Poly/pitch-only input shows possible positions, not detected strings. Configured six-channel input maps displayed strings only on six-string tracks; other string counts show possible positions. Both modes still grade pitch.

Scroll the neck horizontally for higher frets. Left-handed display mirrors the neck without reversing MIDI channel mapping. Targets needing frets above 24 extend the display through fret 36; unsupported positions remain in score feedback.

Select a tablature track with usable string tuning to show its fretboard.

Help & Guide

  1. Open a Guitar Pro or MusicXML score from Scores.
  2. Select your Fishman or other MIDI input in Settings. Choose Poly/single-channel or your configured six-channel Hex layout.
  3. In Practice, choose a track and Realtime or Wait. Both currently grade pitch.
  4. Use Tempo and Loop to work on a section. Play starts with a count-in; Pause preserves results.

Visual feedback is in Practice; track visibility and the optional fretboard are in Display. Audio controls selected/backing-track playback.

Poly fret estimates are optional guidance, not detected positions. Left-handed fretboard orientation does not reverse MIDI channel mapping.
