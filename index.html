Feedback colors and positions

Staff: green marks correct notes; red marks mistakes. Tabs: green marks correct frets on the active target; red marks errors. Historical correct frets stay unmarked. MIDI input tolerance

Review these settings if tracking causes unexpected errors or repeated chords stall. Changing an option pauses practice and clears its results.

Repeated identical chords still need at least one fresh required attack.

Forgives extra strings in chords with two or more pitched strings.

Filters confirmed false starts and soft-note retriggers on the same string.

Written shape ±5 frets, plus open strings. Can hide real mistakes.

Forgives wrong notes shorter than the duration below, including real brief mistakes.

How these settings work

Held notes: For repeated identical chords in all practice modes. Choose Off, One, Two (default) or Three. Two/Three allow continued carryover. At least one required note must still receive a fresh attack. Released notes cannot count.

Extra strings: For chords with at least two pitched strings. Skipped strings lie between written pitched strings; All also forgives outside strings. Ignored input cannot satisfy required pitches. Other enabled filters still apply.

Written X notes need no tolerance setting. An all-X beat requires one fresh MIDI attack at any pitch from any string. In mixed chords, pitched notes are required; identified Hex X-string input is forgiven. Poly cannot identify individual X strings.

Tracking spikes: checks the MIDI sequence, not hand position. It also ignores one stronger retrigger of a completed soft single note (velocity 20 or less), within 60 ms of its onset and 20 ms of its release, on the same string and pitch across the next target. If the next target needs that pitch, it still counts normally. A soft, distant spike must be released within 70 ms and followed within 200 ms by the correct same-string tone at twice its velocity. Alternatively, a wrong onset must be released within 5 ms and replaced within 20 ms by the correct same-string tone at equal or greater velocity. Short correct notes count immediately.

Written range: checks score positions without waiting for a confirming note. Hex checks the reported string; Poly ignores a pitch only if no string fits. It estimates the written range, not your physical hand position. Missing fingering leaves input unchanged.

Brief off-target notes: forgive wrong pitches released before the chosen duration (5–100 ms). At or above the threshold, count the penalty against its original target. Correct pitches still count immediately, including very short notes. This can hide real brief mistakes; it does not prove a note was a ghost. Default 30 ms, adjustable in 5 ms steps or by typing. The enabled choice and duration save per MIDI input.

These tolerances apply in Realtime and both Wait chord modes. String-based rules and the spike filter require Hex input. An all-X beat needs one fresh MIDI attack; in mixed chords, X notes are optional.

Help & Guide

  1. In Scores, open your Guitar Pro or MusicXML file, or try a demo.
  2. Select your MIDI input in Settings. Match Poly or Hex and its channels to your device.
  3. In Practice, choose one guitar track. Try Wait to learn the notes, or Realtime to practice timing.
  4. Press Play. Use Tempo to slow down and Loop to repeat a section. Pause preserves results.

Practice controls score feedback. Display controls zoom, visible tracks and fretboard visibility. The fretboard gear holds its views, labels and left-handed option. Audio controls synthesized playback and recording volumes.

If tracking causes unexpected errors or repeated chords stall, review Practice → MIDI input tolerance.

Both MIDI modes grade pitch; Poly fret estimates are guidance, not detected positions. Left-handed display does not reverse MIDI channels. Back up your browser score library from Scores.

Device settings help

Poly/Hex mode, MIDI channel, Hex base channel and order, pitch-bend range and latency save separately for each selected input in this browser. Select a device before changing its settings.

The last selected input reconnects automatically, including if it appears before the first score loads. While it is unavailable, the app waits without selecting another input. Choosing another device or None replaces that preference; None cancels automatic selection. Use the same browser address and port to retain saved choices.

If a device ID changes, automatic recovery requires a unique matching name and manufacturer. Identically named inputs may require manual selection.

Hex channels run consecutively from the lowest string; Reverse counts downward. The sequence above shows the resulting mapping. Match the pitch-bend range to your device. Early bend corrections follow their own raw note; old bends do not transpose a different note or a restarted attempt. Later bends do not create attacks.

    Alignment help & waveform

    A point matches a chosen measure/beat to a selected recording time. Click the waveform or type seconds to select a time; playback will not change that selection. Add/Update sync point saves it and pauses. Use playhead time only copies the moving playhead into Selected time. A dotted red line marks the selected time; the dark line is playback. Light guides are estimates; clicking a measure or saved point changes only the score target and reveals its measure in the sheet. Recording selection and playback stay unchanged. Drag blue point arrows to fine tune; release resumes from the placed point only if playback was running before the drag. Click the waveform body to seek the recording and score together. Main Play/Pause and Tempo work with Synth audio or Recording. While editing, scoring and practice loops are suspended, and either practice mode allows audible preview. Close the editor to restore normal practice. The 50 ms buttons move the selected point immediately.

    Beat + Bar previews the next beat when the current measure runs out of future beats, including loop returns. Show alternate positions adds faint dashed blue guides for the current target's exact pitches elsewhere on the neck. These are possible positions, not detected fingering or octave substitutions; alternate finger labels stay blank.

    Blue: current target. Gold outline: upcoming. Faint outline: earlier in this bar. Green: required pitch accepted, including alternate positions. Red: existing error feedback. Finger labels use score data only (T = thumb); missing fingers stay blank. Arrows pause and start a fresh attempt at the chosen beat.

    Separate rings show held pitches: green for accepted, red for wrong, purple without a current result. Rings disappear on release. Poly shows possible positions, not detected strings. Configured six-channel input maps strings only on six-string tracks; both modes still grade pitch.

    The selected tablature supplies string count, tuning and capo. Fret numbers are relative to the capo; inlays follow physical frets. Open notes sit outside the nut. String thickness is a pitch cue. Left-handed orientation mirrors the neck without changing MIDI channel mapping.
