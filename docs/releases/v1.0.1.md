# Guitar Trainer Studio v1.0.1

A stable patch release improving library backup guidance and use of taller displays.

- Added a short reminder in Scores that the library is saved in this browser only and should be backed up.
- Expanded README/Help guidance on automatic browser storage cleanup, private browsing, regular backups and restoring through Import Library.
- Long score/folder lists now use more vertical space on tall desktop screens. Short-list minimum sizing and laptop/narrow-screen list limits remain unchanged.

Validation: all 486 Node tests pass. Isolated Chrome checks cover 65-score/folder lists on a tall desktop, compact empty/filtered lists, laptop limits, narrow-screen scrolling and the guide/demo flows. Actual owner display acceptance remains separate. No MIDI, grading, playback, backup-format or preference changes.

Download **Source code (zip)** and extract it to update, or use the hosted app. Back up your library first and retain the same browser/address/port for local storage continuity. Library JSON includes saved scores, folders and saved sync profiles; recordings and app preferences remain separate. Older releases and tags are preserved.
