# Guitar Trainer Studio v1.0.2

Clearer scores, smoother guitar practice, and easier recording alignment.

- Improved notation and TAB layout, including busy scores with chord names and annotations.
- Better handling of repeated measures, tied notes, harmonics and other guitar techniques.
- More forgiving practice for written bends, including bent notes in chords.
- Align recordings visually with movable timing sections, precise adjustments and Undo/Redo.
- Follow lessons through explanations and breaks without being graded during the pauses. Incomplete timing can be reviewed in the optional Draft editor.
- Reload a recording after a playback error while keeping your score and alignment.

Draft timing still needs review before it can be used for graded recording practice.

**Updating:** Back up your library first. Download **Source code (zip)**, or hard-refresh the hosted app. Keep the same browser and local address to retain your saved library and settings.
