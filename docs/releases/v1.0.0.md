# Guitar Trainer Studio v1.0.0

The first stable release of Guitar Trainer Studio: browser-based guitar practice with native alphaTab notation, tablature and playback, synchronized recordings and MIDI performance feedback.

## Changes since Beta v0.0.4

- Light, Soft Light and Dark appearance with saved choices; printing stays black on white.
- Saved notation/tab display choices and tab rhythm controls, plus Print / Save PDF.
- A centered virtual fretboard with an ultrawide width cap, reliable initial sizing and clearer octave markers. Missed targets stay blue on the fretboard; incorrect played notes remain red and notation retains miss history.
- Realtime accepts explicit notes/chords throughout their written target spans, capped at the next onset/rest, with early grace. Wait progression and pitch-based grading remain intact.
- More compact menus and a clearer score library: built-in Demo Scores, alphabetical user folders, title/filename search and filename fallback for untitled scores.
- Download original score files and export individual folders with related saved sync profiles. Import Library restores folder or full-library JSON; separate profile transfer is grouped away from ordinary management.
- Improved sync timeline selection/seeking, reset cursor visibility, recording metadata handling and lesson-receiver timing. Local launchers use localhost; existing Live Server workflows remain supported.
- Updated player guide and developer documentation. The separately maintained private extension is not part of this distribution.

## Download and start

Download **Source code (zip)** below and extract the entire folder. Use a Windows or Mac launcher in **Launchers** with Node.js 22 or newer, or use your existing local server / VS Code Live Server. No frontend build or npm installation is needed. Do not open index.html directly from disk. See README.md or README.html for instructions.

Before updating, download **Backup Library** and keep your recordings separately. The backup includes saved scores, folders, library names and saved sync profiles; it excludes recordings, app preferences and unsaved work. Keep the same browser and address/port to retain local storage. Importing into an existing library preserves current names/folders for identical files and retains distinct sync profiles.

## Validation and practical limits

Release checks passed: **486 Node regression tests**, isolated Chrome guide/demo desktop/phone checks, themes and native printing, score/folder/profile export and restore, and synthetic Poly/Hex Realtime timing checks. Details are recorded in docs/DEV-NOTES.md. Automated checks cover logic and isolated browser workflows; they do not certify every physical MIDI device, browser, score or recording provider. Actual printer/PDF destinations and Mac launcher acceptance remain separate checks.

MIDI feedback requires MIDI input from a compatible guitar system or external conversion software; ordinary guitar audio alone is not recognized. Both Poly and Hex grade pitch, not exact string/fret position. Poly position estimates are visual guidance. Tracking errors can still affect results. A previously observed cross-site Web MIDI/Fishman unplug freeze is not claimed fixed. Online recordings depend on provider availability and embedding permissions.
