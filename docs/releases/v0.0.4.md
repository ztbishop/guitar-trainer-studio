# Beta v0.0.4

Guitar Trainer Studio is a browser-based guitar practice app with native alphaTab notation, tablature and playback, plus MIDI performance feedback. Guitar recognition requires MIDI input from hardware such as Fishman TriplePlay or separate guitar-to-MIDI software; ordinary guitar audio alone is not recognized. Scores and playback can be explored without MIDI.

## Changes since the previous beta

- Expanded score library, backup/import, track mixer, menus, diagnostics and saved preferences.
- Added synchronized local/online recordings, saved sync profiles, video placement and clearer separation between sync preview and practice. Repeat/jump mapping follows native playback order.
- Improved repeated-chord recognition and explicit MIDI tracking tolerances, with independent feedback visibility and pitch-based grading in Poly and Hex.
- Improved virtual fretboard previews, labels, alternate-position guides, orientation and sizing. First use shows Beat + Bar; saved choices take precedence. Accepted held-note tails no longer leave misleading rings on later targets.
- Fixed GPX blank-system rendering for notes without string assignments and rapid Pause during native audio startup; native rendering/transport remain the foundation.
- Added a player-friendly guide, three optional original CC0 demo scores and Windows/Mac ZIP launchers. Hosted use and Live Server need no frontend build; launchers require Node.js 22 or newer.
- Added AGPL-3.0-or-later application licensing, explicit third-party notices/source information and License & Source in Help. alphaTab/native-derived integration retains MPL coverage; fonts, soundfont, Marked and demos retain their respective licenses.
- Prepared static hosting with `.nojekyll` and documented license verification and GitHub Pages setup in [the publishing guide](https://github.com/ztbishop/guitar-trainer-studio/blob/v0.0.4/docs/PUBLISHING.md).

## Download and start

Download **Source code (zip)** below and extract the whole folder. Open the Launchers folder and use the Windows or Mac launcher after installing Node.js 22 or newer. Alternatively, use your existing local web server/VS Code Live Server. Do not open index.html directly from disk. See README.md or README.html for setup, supported score formats and MIDI configuration.

Back up your library before updating and keep the same browser/address/port for local storage continuity. The hosted site has separate browser storage. Main-branch downloads and a future main-based website can include work newer than this tagged beta.

## Validation and limitations

Release preparation passes all 459 Node regressions, isolated desktop/phone Chrome guide/demo/license checks, updater integrity/notice/failure/rollback tests, official alphaTab package check-only, source-patch applicability, syntax and whitespace checks. Earlier feature-specific browser evidence is recorded in DEV-NOTES.md. The owner has confirmed normal real-guitar practice; this release run does not establish every physical device, score, provider, browser or Mac launcher scenario.

Both Poly and Hex grade pitch, not exact played string/fret. Poly position estimates are display guidance. Incoming tracking errors can still create incorrect/missing feedback; tolerances have tradeoffs. A known cross-site Web MIDI/Fishman unplug freeze is not claimed fixed. Fonts/sounds follow upstream-declared licenses; notices and source information are in docs/LICENSING.md. Public Pages deployment, source access while signed out, real Fishman input on the hosted site and actual Mac launcher acceptance remain owner checks.

This is a **prerelease beta**, provided without warranty. Source is AGPL v3 or later with the documented third-party exceptions. Repository visibility and Pages activation are separate owner-controlled steps.
