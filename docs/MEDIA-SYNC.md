# Media & Sync

Implemented 2026-10-13 with bundled alphaTab 1.8.4; playback and editor workflow revised 2026-10-14. Open **More → Media Sync** after loading a score. There is no separate top-toolbar Media Sync button. Opening/closing the editor does not change the playback source or mode.

**While the editor is open: Editing sync · Scoring paused.** Main Play/Pause previews the selected source audibly even if the saved practice mode is Wait. Grading, prior feedback display, practice-loop restrictions and count-in are suspended. Closing the editor pauses playback, restores the saved practice mode/loop choices and prepares a fresh graded attempt. Realtime grading and silent Wait described below apply with the editor closed. Practice preferences remain saved; opening the editor does not switch the audio source or start playback.

## Sources and playback

Main Play reads **Preview** while editing. **Finish editing / Return to practice** and the editor's × both close the editor and pause preview using the existing host restoration path. The selected Synth audio/Recording source and current alignment are retained. Press Play to start practice. Source buttons choose audio only; selecting Synth audio does not end editing. Loop inputs are disabled during editing and player restoration, with a reason in the Loop menu; saved loop choices remain intact. Save profile explicitly to retain unsaved alignment across reloads.

- **Local audio / video:** choose a browser-playable recording. Video displays in the optional Video panel. Audio uses the editor waveform/timeline and does not open a separate player panel. Files stay on disk and are not uploaded or copied into the repository/library.
- **Audio / video URL:** use a direct playable media URL. A lesson webpage/share link usually is not a media file. Access, codecs, seeking and expiring links depend on the host/browser.
- **YouTube:** paste a video link or ID and click Load link. The online iframe API loads only on this action. Embedding/sign-in and available speeds depend on the video; unsupported speeds report an error.
- **Score's embedded backing audio:** loads the recording and existing sync points from a compatible GP file. Original score bytes remain unchanged.

Loading any recording automatically selects Recording without autoplay. You can switch back to Synth audio explicitly.

In the editor, **Load / options** opens source loading, profile naming/selection and secondary settings. It closes after a successful recording load. The **Playback: Synth audio / Recording** buttons choose what the main **Play/Pause** controls; selecting a source does not start playback. These are audio-source choices, separate from Practice's Realtime/Wait choice. The Video panel has no duplicate Play button or speed selector. **Tempo's percentage controls the selected source and score together**, retaining that choice when switching sources. Providers such as YouTube may reject unsupported percentages, leaving the previous speed intact. There is no synthesized-score/media audio mix.

**Realtime grades MIDI with either audio source.** Recording targets use the saved sync points to map each expected attack into recording milliseconds; real-time hit windows, latency compensation, pitch rules and note identities remain unchanged. Provider-clock samples drive grading, with bounded interpolation that stops during pause/buffering. Alignment, source and speed changes start a fresh Realtime attempt. The original score timeline is retained for notation, Wait targets and synthesized playback.

**Wait keeps playback audio paused and muted for either source**, while seeking the selected recording/video to each solved target. The independent Wait click/count-in remains available. Switching to Synth audio restores synthesized playback and the previously captured practice position; shared Tempo speed remains current. Source/unload/score changes pause and dispose old media, invalidating stale asynchronous work. A new score clears the current recording/editor session; saved profiles remain. Practice, Tempo and Loop settings remain available with recordings selected.

YouTube loading may take a few seconds while the video length becomes available. If a video returns **code 150** on `http://127.0.0.1:8081/`, try the same server at [http://localhost:8081/](http://localhost:8081/) and load the same score/link. This resolved the tested All Of Me video; other videos may behave differently. These addresses have separate browser libraries and preferences: your original data stays at the original address. Use Backup Library/Import Library if you want to transfer saved scores and sync profiles. A video playing on youtube.com does not guarantee embedded playback in every context.

## Video position

Video remains in its separate panel; audio-only sources leave this panel hidden without changing its saved visibility preference. **Edit sync** toggles the editor directly. Selecting Recording or using Play preserves saved visibility; it does not force a hidden panel back on. Video, editor and fretboard have labeled × buttons that hide the panel and update the saved visibility choice without discarding work. Open **Load / options** for visibility and placement controls.

Editor and fretboard now have top-edge dividers: drag, or focus and use Up/Down. Double-click or Home resets an individual auxiliary panel; Media & Sync → Reset panel sizes resets all three sizes. Bounded editor/fretboard preferences are saved in `gts.workspacePanelSizes` and fitted to the viewport while reserving score space. Small screens and opening all panels may require vertical scrolling. The native score, zoomed timelines and readable phone fretboards intentionally remain scrollable; desktop fretboards fit their panel without unnecessary horizontal scrolling.

During sync editing, the fretboard is temporarily hidden and excluded from panel fitting. Finishing restores its saved visibility and size; no display preference is changed. Zoom stays immediately above the timeline and sticks within its scroll area. A horizontal divider separates the purple score-target lane from the red recording-time lane. The seconds arrows step by 0.01 s; typing retains three-decimal precision.

The editor's first-use/reset preferred height is 320 px (2026-10-28). Existing saved heights remain intact; double-click its divider or press Home while the divider is focused to reset it. Smaller viewports fit the panel and retain its internal scrolling. The bottom status line remains for errors and action confirmations; redundant editing reminders are hidden. Detailed field/lane guidance lives under **Load / options → Alignment help & waveform**.

Opening the editor through More or Edit sync also opens **Load / options** when no recording is attached and loading is not already in progress. With a recording attached, reopening goes directly to the editor. This supports repeated open/close fine-tuning without repeatedly dismissing the source picker.

The timeline renders only its visible viewport, keeping text sharp at extreme zoom without allocating a recording-wide image. Ruler labels use round intervals that become finer as you zoom, down to milliseconds when appropriate. Waveform detail remains limited by the decoded envelope; zoom does not invent additional audio samples. Clicking, dragging and playback scrolling retain recording-wide coordinates.

In **Video & editor layout**, choose Above, Below, Left or Right of score. First use defaults to Left; valid saved preferences and profile placements take precedence. Missing/invalid profile placement also falls back to Left. Left/Right place the recording beside the native score. Drag the divider, or focus it and use arrow keys, to resize. Narrow screens stack automatically while retaining the wider-screen choice. Placement, divider proportion and player/editor visibility persist in localStorage.

**Float video** uses browser picture-in-picture for local video or direct video URLs where supported. It is disabled for audio and YouTube's iframe, with contextual help. YouTube may offer floating playback through the browser's own controls. Our app does not control floating videos from unrelated TrueFire/other-site tabs.

## Alignment

During editing, clicking notation/tab retains native seeking (black playhead) and selects the corresponding measure/beat triangle and Add/Update action. The red dashed recording time stays unchanged. The target follows the repeat occurrence chosen by native seeking; subdivisions receive their own selected triangle. Triangle clicks choose the score target and seek the sheet cursor/black playhead to its mapped recording time, preserving the red dashed time. Each repeat triangle identifies a specific pass; sheet clicks keep native repeat navigation, shown in the Measure selector and highlighted triangle. The blue sheet cursor continues to indicate playback. Waveform/time-ruler clicks move playback and red time while keeping the score target. Add/Update saves the pairing explicitly.

**Paste existing timing:** after loading a score and recording, open **Load / options → Paste sync points** disclosure. Paste the complete Soundslice JSON array for the matching arrangement and recording, then click **Apply pasted sync points**. This replaces only the current recording's alignment; score and recording stay loaded. The app validates playback measure order, complete endpoint and recording duration before changing anything. Invalid/mismatched data leaves alignment intact. Undo restores the previous points; Save profile retains the change. Pasting does not start playback or finish editing automatically. Use timing from the same arrangement and recording, then check audible alignment. Clipboard access is manual; the app never reads it itself.

Initial alignment spans the recording and follows source tempo changes. It is an estimate; intros, teacher explanations, repeats or different arrangements need adjustment. Light guides show estimated measures and beats; blue anchors are actual alignment points. Guide positions update between anchors without creating additional saved points. Repeated measures are labeled with their separate passes.

The timeline follows alphaTab's expanded performance order, including recognized repeat signs, alternate endings and D.C./D.S./Coda/Fine directions. Each visit to a written measure has its own occurrence and recording time. For example, D.C. al Coda can play measures 1–4, return to 1–2, then jump to 5–6; the second visits to 1–2 belong later in the recording. The recording must follow the same form. Arbitrary printed text or an arrangement that skips/adds repeats is not automatically interpreted or reconciled. Add anchors for the appropriate pass to improve timing; Start/End alone do not guarantee alignment throughout a performance.

2026-10-24 verification: native mapping and isolated Chrome checks cover ordinary repeats, first/second endings, D.C. al Coda, D.S. al Coda and D.C. al Fine. Generated GP files are imported through the real app; paused seeks hit distinct playback occurrences, and actual HTML recording playback/cursor samples traverse every visit. Synthetic silent WAV supplies the clock; these checks do not establish audible alignment or every score/provider combination. Real video/recordings and physical MIDI remain owner acceptance checks.

Magnifier zoom keeps measure/time labels readable and redraws the visible waveform detail with thin strokes. Crowded measure labels are hidden until there is room to show them; their arrows still work, and selected/saved point labels take priority. Zoom changes the display only, preserving alignment and saved points.

1. Select a measure/beat using a timeline arrow/measure number or the Measure and Beat fields. Timeline clicks also seek playback to the mapped beat/pass; the Measure and Beat fields select/reveal without seeking. Both preserve the chosen red recording time. Beat 1 is bar start; numerator + 1 is bar end (beat 5 in 4/4). The fields show the target measure/beat and selected recording seconds; the compact status above them shows the moving playhead and paused grading/loops reminder.
2. Click the waveform to select a recording time and listen from there. Playback can continue, but **Recording seconds** stays at the clicked location. **Add sync point** saves that selected time for the chosen measure/beat and pauses. If the target already has a point, the button says **Update sync point**. The action always uses the visible selected seconds, never a later playhead time. Seeking/Play/Pause do not save points; unchanged updates add no redundant Undo step.
3. Type exact seconds into **Selected time**, or click **Copy playhead time** to copy the moving playhead into it. Copying does not seek, pause or save. Use the same Add/Update button to apply the selected value. A dotted red line/triangle marks the selected time in the waveform; the dark line moves with playback. Recording-time selection is retained until a waveform seek, typed entry, point adjustment or playhead-copy action changes it; choosing a measure or saved point does not replace it.
4. The selected target has a purple arrow/short line confined to the measure strip. A dark moving playhead is confined to the waveform below; blue arrows are saved points and light arrows are estimates. The opening score anchor says **Start** and the final endpoint says **End**, while intermediate anchors identify their beat/repeat. Drag saved arrowheads in either direction to fine tune; an actual drag pauses during movement and stops before neighboring points or recording bounds. Releasing seeks to the placed time and resumes only if playback was running before the drag. Adjacent **50 ms buttons immediately move the selected saved point**, including the seconds field; no Add/Update click is needed afterward, but save the profile to retain it. Each adjustment also seeks to that marker's new time: a running preview continues from there, while a paused preview stays paused. Existing keyboard behavior is unchanged.
5. Magnifying-glass buttons change timeline zoom by 20%; the percentage resets it and **Fit recording** zooms out to show the entire recording. It changes only the view, not alignment. Zoom retains the selected point or playhead on screen, subject to scroll bounds. **Click the waveform body to seek both recording and native score cursor, even while paused.** Guide/point selection uses the arrowhead strip rather than intercepting clicks through the waveform. Triangle clicks seek the selected pass without changing the red recording time or saving a point. Delete point, Undo and Redo remain available. At least two points are required, and both score order and recording time must increase; invalid changes leave alignment intact.
6. **Save profile/Save changes** and unsaved status remain on the main editor toolbar. Profile name/picker are in Load / options. Save explicitly before switching recordings, profiles or scores; the unsaved indicator does not prevent switching.

Deliberate media seeks reveal the destination cursor inside the sheet viewport even while paused. This is a one-time reveal, not a change to the saved **Auto-scroll during playback** preference. Playback following still respects that setting; you can scroll elsewhere while paused until the next deliberate seek.

During editing, waveform clicks **seek and continue if playing**, or **seek and remain paused if paused**. Measure-guide/saved-marker clicks select the score target and seek its mapped recording time, preserving red recording seconds and the running/paused state. They select Recording if needed, as waveform clicks do. Merely clicking an existing marker does not pause; dragging pauses during movement, then resumes from the placed time only if previously running. Add/Update sync point pauses after saving the selected time. Preview can audition recording material beyond a moved End anchor while the sheet cursor stays near the score end. Paused seeks never complete/grade the song. Each 50 ms adjustment automatically auditions from the adjusted marker when playing; it does not merely offset the current playhead by 50 ms.

Supported local recordings automatically build a waveform. **Load / options → Alignment help & waveform → Retry waveform** retries drawing this visual representation of the sound; it does not alter audio or timing. The envelope includes both audio channels and approximately 1 ms detail (up to 900,000 bins), with only visible screen columns drawn at each zoom. YouTube/URL waveforms are absent in this increment. Waveforms are not saved. Files over 80 MB or 15 minutes use timestamp editing to avoid large decoded audio allocations. Some video containers play successfully but cannot be decoded into a waveform; synchronization works without it. Stale decoding results cannot replace a newer recording's waveform.

When a recording has no waveform, its timeline shows a faint baseline and **Waveform unavailable · Click timeline to seek**. Timestamps, the playhead and alignment tools still work normally. The hint stays visible during zoom/scroll and disappears if an actual waveform becomes available. It does not represent sound data.

## Saved profiles

Save stays on the editor toolbar. **Load / options → Profile name & saved profiles** contains the current score's profile picker/name plus Delete, Export/Import and Manage all profiles. New profiles default to the recording name. Save updates a selected matching profile; a different recording creates a new one. Deleting keeps the score, recording and working alignment. Existing version-1 profiles remain compatible. The duplicate point list is in **Alignment help & waveform**: Start/End mark the first/last alignment points; intermediate entries say Measure/beat → recording time. Clicking an entry selects its score target for editing while preserving the selected recording time and playback. Repeat labels appear only after the first occurrence.

Profiles use IndexedDB beside the score library. They contain original score SHA-256 identity, recording metadata, duration, points, name and placement, not recording bytes, waveforms, grades or MIDI settings. Local profiles match automatically by filename, size and modification time; choose the file again after reload. If those details changed, select the saved profile first, then choose the recovered local file to relink it without rebuilding sync points. The relink is saved after the points validate against the current score measures and recording duration. A profile from another score or a different source type is not applied. Different original score bytes get a different identity. Restored online profiles require explicit Load link; reload does not automatically contact or play third-party media.

Export downloads all profiles in a standalone version-1 media-sync JSON. Import validates before an additive write and skips identical settings. Library backup version 2 includes profiles; version-1 score backups still import. Browser origin/profile/storage-clearing boundaries are the same as the score library. Keep external backups and recordings.
